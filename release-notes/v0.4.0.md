EarthSciIO v0.4.0 makes the run window behave the same in every track (Rust,
Python, Julia), so an integrator can drive a provider in its own model time
from `t0` to `tf`. See
[`CHANGELOG.md`](https://github.com/EarthSciML/EarthSciIO/blob/v0.4.0/CHANGELOG.md#v040)
for the full list.

- **Time origin (`spec/esm-sources.md` §4):** built with `time_origin=`
  (Python, Julia) or `DataSource::time_origin(origin)` (Rust), a provider
  takes and returns every time as seconds from that origin: `sample_at`,
  `refresh`, the run window, `prefetch`, `refresh_times`, `window_records`
  and a `PrefetchGroup`'s boundaries and anchors. Opt-in; without an origin
  nothing changes. The origin must be a whole second (`time_origin_invalid`).
- **Records serving a window (§2.6):** the three tracks agree on them — the
  record in effect at the window start, every record inside, and with
  `records_per_sample = 2` the one after. New `window_records` lists them.
- **Closed window end (§2.3):** new `refresh_times_closed` adds the refresh at
  `tf` when a record is anchored there, so it can be a tstop without an
  epsilon. `window_records`, `prefetch` and `PrefetchGroup` serve that
  refresh too.
- **`PrefetchGroup`** schedules a member whose window holds no record anchor:
  its boundaries include run-window starts (`spec/prefetch.md` §3.2).

### Breaking changes

- **All tracks:** a run window that starts before the source's `start`, ends
  past its `end`, or is empty is refused when the provider is built, with
  code `esm_window_uncovered` (Python and Julia `WindowNotCovered`, Rust
  `Error::WindowNotCovered`). Python and Rust used to clamp it to the data and
  could run on no records at all. `prefetch(window)` (Python, Rust) checks
  its window the same way.
- **Julia:** a window inside a single record's interval is no longer refused
  ("holds no record"); it has no refresh times.
- **Rust:** `sample_at`, `refresh`, `refresh_with_select` and
  `sample_windows_at` take `impl Into<ProviderTime>` (an `OffsetDateTime` or
  an `f64`); `DataSource` gains a public `time_origin` field. Rust also keeps
  the fraction of a fractional-second window start in group boundaries,
  `Sample::anchor` and the `decode_latency` hook, matching Python and Julia.
